# Mamiya-Sekor C 80mm F1.9 REHOUSE clean-room fixture

This is the second independent named-lens rehearsal. It intentionally uses a
different maker, vocabulary, and cultural cue from the Helios fixture so a
fresh Codex task can expose cross-job leakage (for example `T*`, `M42`, or
`ZEISS`) before it reaches a printable file.

The approved circle keeps `80` as the first visual read and `F1.9` as the
second. The remaining text is secondary: `MAMIYA-SEKOR C`, `645`, and
`REHOUSED MEDIUM FORMAT`. The graphic uses broad black/charcoal/gray/ivory
letterpress blocks, a 6×4.5 frame grid, and stepped registration bands. It is
style/specification equivalent rather than a pixel-perfect generative copy;
the locked master and prompt hash define the reproducible boundary.

The [Mamiya M645 service instructions](https://www.suaudeau.eu/memo/Manuels/Mamiya_M645_Service_Manual.pdf)
identify the multi-coated 80mm f/1.9 C, M645 bayonet, and 67mm filter size.
That 67mm number is deliberately not used as a cap fit diameter. The period
[Mamiya 645 lens-series brochure](https://www.pacificrimcamera.com/rl/00302/00302.pdf)
provides the modular-system design language. A [True Lens Services rehouse
account](https://www.truelens.co.uk/my-mamiya-645-lenses-nathan-thompson-dop)
documents modern cinema rehousing of the 80mm f/1.9 donor; the artwork keeps
the donor's F1.9 text and uses a qualified family-level rehouse cue rather than
turning a later T1.6 housing into the original specification.

## Three adapter-envelope scenarios

The jobs exercise the actual gripping diameter and show how a radial adapter
wall is counted: `mating = nominal ring + 2 × radial wall`. They are synthetic
repeatable test envelopes, not measurements of a particular user's lens.

| job | envelope | mating diameter | liner |
| --- | --- | ---: | --- |
| `95mm` | nominal rehoused PL front (95 + 2×0) | 95.0 mm | 1.5 mm foam |
| `85mm` | 80 mm ring + 2.5 mm radial step-up wall | 85.0 mm | 1.5 mm foam |
| `77mm` | 72 mm ring + 2.5 mm radial step-up wall | 77.0 mm | 1.5 mm foam |

All jobs use `assembly_mode = "auto"`, a 0.2 mm nozzle, provisional 20%
foam compression, and neutral `light_tapered` ribs enabled by default (12
shallow ribs). A real user must replace the synthetic value with the measured
cylindrical surface the cap grips, include any adapter wall, and print a
same-material coupon. The face/relief diameter follows that measurement; no
second relief-diameter or structure question is needed.

## Retained 3MF outputs

The checked-in snapshots below were generated by the clean-room runner with
OpenSCAD `Manifold` and Bambu Studio's A1 mini 0.2 mm profile. Each has a
portable `.manifest.json` sidecar containing input/output hashes, package
counts, tool banner, and (for the sliced file) non-empty G-code size.

| `artifacts/mamiya-sekor-c-80-f1-9-rehouse-85mm-native.3mf` | native OpenSCAD Core 3MF | verified, unsliced |
| `artifacts/mamiya-sekor-c-80-f1-9-rehouse-95mm-native.3mf` | native OpenSCAD Core 3MF | verified, unsliced |

The package verifier checks ZIP CRC, Core XML relationships, model/component
references, finite vertices, triangle indices, and G-code presence. It does
not prove a physical foam fit; inspect the slicer preview and measure a coupon.

## Reproduce from a clean checkout

```sh
python3 scripts/smoke_rehouse.py \
  --fixture examples/fixtures/mamiya-sekor-c-80-f1-9-rehouse \
  --bambu never --json
# With OpenSCAD and compatible Bambu profiles:
python3 scripts/smoke_rehouse.py \
  --fixture examples/fixtures/mamiya-sekor-c-80-f1-9-rehouse \
  --bambu auto --require-external --keep-workdir --json
```

Use `--artifact-dir examples/fixtures/mamiya-sekor-c-80-f1-9-rehouse/artifacts
--force-artifacts` only when deliberately refreshing retained 3MF snapshots.
The runner copies only the brief, prompt, master, and `jobs/*/job.toml`; it
never reuses old `out/` directories or rewrites the approved artwork.

The report separates deterministic file/projection checks from physical fit:
`fit_status` remains `UNVERIFIABLE_UNTIL_COUPON_MEASUREMENT` until the foam,
ribs, material, and real lens/adapter are physically tested.
